# Contributing

Thanks for helping build EL-VERSE BACKEND (ARC CORE)! Please open issues and PRs against `main`. Follow conventional commits and include tests where appropriate.

Note on Verse IDs: All new user sign-ups will be assigned a unique VERSE ID (prefix + 8 digits). If your change involves user creation, wallets, transfers, or gifts, ensure `verseId` and `fullName` handling and snapshots are preserved in migrations and tests.
